成员1交付包｜开发版4.1｜使用说明

这份包包含“识别右滑并输出下一页指令”的模块和P01测试证据。拿到包后，先按第2节回放已有数据，再按分工接入。
当前验证页显示触发次数和记录；它不会直接控制桌面PowerPoint，也还不是完整的项目网站。

1. 文件分别给谁用

01_code：当前代码、启动器和模型。成员2主要使用；保持目录结构不变。
02_profiles：两份有不同用途的配置，见第3节。
03_validation：最新两份轨迹JSON、两段录屏、检查报告与结果汇总。成员3主要使用。
04_docs：成员2_接口接入.md、成员3_校准与实验.md，分别看自己的详细说明。
MANIFEST.sha256.json：文件校验清单，日常运行不用打开。

P01是成员1的参与者编号。P01个人配置不是三个人通用的手势模型；其他人要正式测试个性化效果，需要录自己的示范和校准资料。

2. 第一次打开：先回放，不需要摄像头

以下双击启动方式适用于Windows。请用Chrome或Edge。

① 如果收到ZIP，先右键“全部解压”，进入解压后的整个文件夹。不要在压缩包里直接运行，也不要只复制HTML。
② 电脑需要Python 3，且python命令可用。没有安装或不确定时，看第6节。
③ 打开01_code，双击start-development.cmd。出现“Serving HTTP…”并且窗口保持运行，表示本地服务已启动。窗口不要关闭。
④ 启动器不会自动打开浏览器。手动复制下面完整网址到浏览器地址栏，按回车：
   http://localhost:8766/development-v41/index.html
   应看到标题“手势识别开发验证4.1”。只打开localhost:8766可能看到文件列表，使用上面的完整网址。
⑤ 点击网页“加载配置”，在文件选择框中进入本交付包的02_profiles，选择：
   P01_calibrated-profile_v4.1-development.json
   加载后应显示：模式calibrated · 正例9 · 反例16 · 已触发0次。
⑥ 不用启动摄像头。点击“加载轨迹回放”，在03_validation里选择：
   P01_livecheck-v41-command-run.json
   回放完成应显示已触发5次。
⑦ 再点击“加载轨迹回放”，选择：
   P01_livecheck-v41-natural-run.json
   回放完成应显示已触发1次。这是系统保留的误触，不是操作错误。

两份回放是独立运行，结果应分别是5和1，不是累加为6。这个步骤用于确认包可以运行，不是新的实验结果。

3. 为什么有两份配置

日常运行和上面的回放，只加载：
P01_calibrated-profile_v4.1-development.json
——当前4.1个人校准配置，9正例16反例。

另一份P01_initial-profile_v4.json：
——仅供成员3读取原始5个个人示范、构造参数一致的初始模板对照。
——名字中的v4记录它的来源；包内没有旧v4引擎。
——不要用它替代当前配置做日常验收。具体对照方法见成员3说明。

配置JSON是数据，选择“加载配置”导入，不需要编辑文件内容。普通运行不需要npm install或Node.js；Node.js只用于可选的检查和回放脚本。

4. 如需试摄像头或录自己的示范

先停止当前运行，再点击“启动摄像头”，按浏览器提示由使用者允许摄像头。等预览正常并出现“已检测到右手”后操作。

P01本人可加载当前P01配置试用：面对摄像头，右手向身体右侧滑动一次。预览已经镜像，画面里的手也向右移动；不要再反过来做。完整手掌在画面中，避免强逆光。每次结束将手移出画面约一秒再做下一次。每次观察触发数是否只增加1。

其他组员可以加载P01配置检查程序是否工作，但不能保证识别你们的动作，也不能把这个结果当成自己的个性化实验。
要录自己的初始示范：另开一个新的开发页标签（初始状态正例0、反例0），先不加载P01配置；启动摄像头，等右手被检测到后点击“录制正例”，右滑一次，停住并点击“结束示范”。分开完成3–5次并确认正例计数增加，然后点击“导出配置”，按自己的编号保存。这里仅建立个人初始示范；后续试讲标注与校准按成员3说明实施，不是点击一个按钮就自动完成。

加载配置会停止当前源并清空本轮轨迹/事件；重新启动摄像头也会重置本轮记录。需要保留结果时，一定先点击停止，再立即导出，之后才加载配置或开始下一轮。

“导出轨迹与事件”通常下载为gesture-run.json，“导出配置”下载为gesture-profile.json。查看浏览器下载记录或下载文件夹，导出后立即按参与者、版本和任务重命名并另存到自己的实验目录。网页不会自动把文件放进本交付包。

6. 常见问题

• 双击后没有“Serving HTTP…” / 提示找不到python：
  先确认Python 3已安装并配置PATH。可在01_code文件夹的资源管理器地址栏输入powershell回车，再运行python --version，应输出Python 3.x。若只有py命令可用，可在同一窗口运行：
  py -3 -m http.server 8766 --bind 127.0.0.1
  保持窗口打开，再用第2节网址访问。

• 提示端口8766已占用：
  若是自己之前启动的同一份服务，可复用。若不确定它服务的是哪个文件夹，在01_code中的PowerShell运行：
  python -m http.server 8767 --bind 127.0.0.1
  再访问 http://localhost:8767/development-v41/index.html 。

• 浏览器无法连接 / 404：
  检查服务窗口还在运行、端口一致、网址完整、代码已完整解压。不要直接双击index.html以file方式打开。

• 摄像头黑屏或访问被拒绝：
  由使用者检查浏览器对localhost的摄像头权限，选择正确设备，关闭可能占用摄像头的会议/相机应用后重试。没有摄像头也可以先按第2节回放。

• 一直提示未确认右手 / 触发结果不同：
  先检查配置是否9正例16反例、页面是否4.1、右手完整入镜及光线。不要反复重录来挑选好成绩。保留导出的run和现象，交给成员1排查。

• 模型加载失败：
  确认01_code/vendor完整保留，并通过本地HTTP访问。模型、wasm和许可证已随包提供，正常运行不需要在线下载模型。

非Windows电脑不能双击.cmd；可在01_code目录用python3 -m http.server 8766 --bind 127.0.0.1启动，再打开同一网址。当前包未在组员各自电脑上逐台验证，有问题请发完整错误提示和使用步骤。
