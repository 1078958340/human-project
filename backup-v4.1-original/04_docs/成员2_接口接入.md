## 最小识别连接代码

下例放在01_code目录中的ES模块里；nextSlide由你的幻灯片播放器提供，video为页面video元素，profile为JSON解析得到的配置。

```js
import {createTracker, watchVideo} from './tracker.mjs';
import {createRecognizer} from './development-v41/recognizer-development.mjs';

const tracker = await createTracker({sourceMirrored:false});
const recognizer = createRecognizer(profile);
const frames = [], events = [];
const stream = await navigator.mediaDevices.getUserMedia({
  video:{width:640,height:480}, audio:false
});
video.muted = true;
video.playsInline = true;
video.style.transform = 'scaleX(-1)';
video.srcObject = stream;
const cancel = watchVideo(video, tracker, frame => {
  frames.push(frame);
  const event = recognizer.push(frame);
  if (event) {
    events.push(event);
    nextSlide(); // 每个事件调用一次；不要自行按每帧再翻页
  }
}, error => console.error(error));
await video.play();

function stop() {
  cancel();
  tracker.close();
  stream.getTracks().forEach(track => track.stop());
  video.pause();
  video.srcObject = null;
}
```

正式应用把上述启动代码放在用户点击启动的处理函数中，用try/catch展示错误，并在失败、切换源、重复启动及离开页面时释放资源；完整处理参考demo.mjs的start/close。每次新启动或新视频源都新建tracker和recognizer，不能继续使用上一轮的时间戳状态。

## 数据约定

帧frame含tMs（媒体时间毫秒，严格递增）、aspect、hand、side、coordinateSystem、sourceMirrored、trackerVersion、handScore、hands。hand为已转成身体右侧坐标的右手21点；hand:null表示未可靠选中。即使hand:null也要传给recognizer.push，以维持连续性与解锁判断。不要再次翻转hand。

事件含type:'next_page'、tMs、startMs、endMs、positiveDistance、negativeDistance和frames。startMs/endMs是系统候选窗口，不是用户意图真值。不要用window长度冒充响应延迟。

导出应保存version:1、engineVersion:'dtw-v4.1-development'、trackerVersion:'right-hand-v4'、mode:profile.mode、实际profile、frames、events。新增加的任务开始/结束和人工标注建议放在独立metadata/labels中，不改既有tMs。

校准后成员3返回同结构profile，重新createRecognizer(nextProfile)。不要只改页面上的initial/calibrated文字。

录像分析调用scanVideo（参考demo）；原始非镜像摄像头录像sourceMirrored:false，确实镜像过的录像才设true。CSS预览镜像不等于源文件镜像。整个浏览器录屏用于人工核对，不能直接当原始摄像头视频输入模型。

验收：一次动作一页、连续5次不重复；停止后释放摄像头；两轮导出互不混合；有手/无手提示清晰；到最后一页如何处理由播放器决定。预览实时识别和离线回放均需要保留误触结果。
