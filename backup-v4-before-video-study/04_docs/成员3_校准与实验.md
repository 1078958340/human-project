# 成员3的标注、自动校准与实验

P02 已提交一段带五次意图的试讲视频及个人配置。原配置、提取后的两手轨迹、标注、冻结的 A/B/C 配置、样例来源和开发报告位于工作区的 `P02_calibration`。开发回放覆盖新旧识别逻辑的差异。后续的正式指标使用新录视频。

## 录制下一组验证材料

1. 录一段命令轮，分别做已注册的右滑、握拳和张手，记下每次有意触发的动作和视频秒数。每类可做数次，动作之间留出恢复的时间。
2. 录一段自然讲解轮，保留日常双手动作。若全程没有主动触发，标注空列表。有主动触发则逐条记录，任务类型写混合轮。
3. 提交原始摄像头视频。两段视频都使用同一套冻结配置对比，验证视频不补样例、不改阈值。若之后还要用验证视频调参，应把它另记为开发资料，再录新的验证数据。

## 标注格式

任务起止和意图窗口使用源视频的媒体毫秒。时间来自用户提交的全部意图。秒数较粗时可以逐帧定位动作，保留用户原始时间作为来源。以下是结构示例。

```json
{
  "version": 1,
  "timeline": "media-ms",
  "complete": true,
  "runId": "从轨迹文件复制",
  "participantId": "P02",
  "rawVideo": {"file": "validation.mp4", "offsetMs": 0, "sha256": "从轨迹文件 source 复制"},
  "task": {"kind": "command", "startMs": 0, "endMs": 30100},
  "intentions": [
    {
      "intentId": "command-01",
      "startMs": 5200,
      "endMs": 5850,
      "gestureId": "从配置复制",
      "actionId": "next_page"
    }
  ]
}
```

纯自然轮使用 `natural` 和 `intentions: []`。有意图与自然活动同录时使用 `mixed`。可为自动提取的正例额外填写 `sampleStartMs`、`sampleEndMs`，并用 `activeHandHint: {atMs, imageX}` 标记目标手在原画面中的横坐标。手部提示仅用于取样，识别回放不读取它。

## 本地执行

在交付包根目录运行。视频提取使用 Python 的 OpenCV 和 MediaPipe，并读取随包的 Hand Landmarker 模型。运行分析和构建实验配置使用 Node.js。`--mirror` 根据源文件的像素方向填写，P02 本次校准使用 `mirrored`。

```powershell
python ./01_code/extract-study-video.py "原视频.mp4" "轨迹.json" --mirror mirrored
node ./01_code/study-video.mjs calibrate "原配置.json" "轨迹.json" "意图.json" "新的实验目录"
node ./01_code/study-video.mjs validate "冻结的实验目录" "独立轨迹.json" "独立意图.json" "新的验证输出目录"
```

提取器会记录原视频 SHA-256、模型 SHA-256、提取工具版本和时间戳。在校准和验证中使用同一套提取方式。校准命令保存三份配置和各自校验值。验证命令校验配置内容、拒绝重用校准视频，并用同一轨迹独立回放三份配置。

| 组别 | 模板 |
| --- | --- |
| A | 原个人配置的示范和绑定，在 v4 上运行 |
| B | A 加上有意标注内可用的漏检或错类正例 |
| C | B 加上从真实误触中提取、去重并通过校准回放检查的反例 |

三组共享引擎、手势集合、功能绑定、阈值和输入轨迹。使用 `{earlyMs: 100, lateMs: 350}` 对齐判定时间，每个意图和事件最多配对一次。其他时间的实际触发计为误触。另列错类、错绑定与同一意图的重复触发。追踪中断和未达阈值的候选只作诊断。重复触发的真实动作不会自动成为反例。提取器会记录来源和跳过原因，轨迹不足时不凭空补样例。

完整的用户意图标注直接驱动自动取样。JS 接口位于 `custom-gestures/auto-study.mjs`，导出 `calibrateStudy` 和 `evaluateStudy`。旧的逐条人工复核接口仍保留在 `study.mjs`，适用于手上缺少完整意图标注的其他流程。播放器是否执行动作可另看浏览器导出的 `actionResult`，统计端到端延迟需要独立记下人工起手和呈现时间。
