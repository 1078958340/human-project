Human Project｜自定义手势 v4
更新于 2026-11-23

新版从个人示范学习静态手型和短动态动作。同一画面有双手时分别追踪，任一只手都可完成已注册手势。短动态可由掌心位移或手指变化完成。每类可保存正反例并修改功能绑定。验证页支持识别日志和三张演示卡片，完整播放器由成员2接入。

一、在 Windows 上启动新版

1. 保留整个交付目录，打开 01_code，双击 start-custom-gestures.cmd。保持服务窗口运行。
2. 用 Chrome 或 Edge 打开 http://localhost:8766/custom-gestures/index.html 。
3. 也可以在 01_code 目录的 PowerShell 运行 python -m http.server 8766 --bind 127.0.0.1 。若 Python 通过启动器安装，将 python 换成 py -3 。如果 8766 已被其他服务占用，将命令和网址中的端口同时改为 8767。

页面需要通过 localhost 的 HTTP 服务打开。MediaPipe 模型、脚本和 WASM 已随包提供。浏览器运行无需 npm、Node.js、GPU 或 API 密钥。Node.js 用于命令行检查和成员3接口。

如需从带标注的视频学习，打开 http://localhost:8766/custom-gestures/video-study.html 。选择当轮示范配置、视频和镜像方向，然后逐行填写“开始秒数 结束秒数 手势名”，或导入标注 JSON。新实验的 A、B、C 统一使用较灵敏设置，包括掌心／手型分通道和放宽后的匹配距离。学完可下载 C 配置、冻结实验包和逐事件结果。切换到回放模式，导入实验包并选择另一段视频，即可按包内保存的三组配置评估。

二、录制个人示范和试用绑定

1. 在“手势配置”填写并保存参与者编号（本人暂用 P02）。添加容易区分的手势。保持握拳可选“静态手型”。掌心滑动和握拳再张开可选“短动态动作”。两只手可以同时入镜，注册时让目标手势清楚可区分。
2. 选中类别，设置名称和功能后点“保存手势设置”。可选择下一页、上一页、暂停／恢复手势翻页，或暂不绑定。更改绑定保留类别 ID 及全部示范。
3. 点击“启动摄像头注册”并允许摄像头。选好类别后点“录制正例”，可以随后再把手放进画面。静态手型摆稳后点“结束示范”，点击前短暂移开仍可保存最近的稳定片段。动态手势只做一遍，完成后稍停再结束。可先录一条试用，每类后续建议录 3–5 条。反例用于过滤会被误认成该类的姿势或动作。
4. 导出 v4 配置。完成注册后点击“停止”，再点“启动摄像头识别”。从第 1 页开始，翻页到边界时保留当前页。暂停期间仍识别动作并写日志，恢复手势仍可执行。静态手势触发后先松开或换回自然手型，才做下一次。追踪中断按次数汇总，完整诊断在运行 JSON 中。
5. “分析原始录像”用于原始摄像头视频。仅当源文件已镜像时先勾选镜像选项。摄像头预览的 CSS 镜像与文件是否镜像是两个设置。“回放轨迹 JSON”可用当前配置重算新版或旧版的手部关键点轨迹。配置与运行记录均需手动导出。

已有 P02 标注视频已用于自动校准。三份冻结配置和报告保存在上一级工作区的 P02_calibration/experiment-v4。可导入 C-profile-v4.json 试用。后续请另录命令验证轮和自然讲解验证轮，提供原始视频与全部有意指令的时间及动作。具体方法见 04_docs/成员3_校准与实验.md。

三、旧版 4.1 与 P01 基线

旧入口 http://localhost:8766/development-v41/index.html 。启动同一个本地服务后，加载 02_profiles/P01_calibrated-profile_v4.1-development.json，再分别回放 03_validation 中原始 command 和 natural 两份 run。每次运行独立，预期分别为 5 次触发和 1 次历史误触。P01 的初始配置为 5 正例，4.1 校准配置为 9 正例和 16 反例。

v2 和 v3 配置可以导入升级。v3 的类别、功能绑定、样例和类别距离阈值均保留，部分全局分段参数使用新版值。4.1 配置继续由 4.1 入口加载。v4 可重放旧 run 已保存的关键点。03_validation 的 screen.mp4 是浏览器录屏，上传追踪应使用摄像头原始录像。

四、检查与接口

在交付目录运行以下命令（需要 Node.js，本轮使用 v24.15.0）。

  node ./01_code/check-custom.mjs
  node ./01_code/check-development.mjs

合成检查涵盖静态手型、手指短动态、掌心滑动、双手同框、拒绝、重复触发和配置兼容。旧 4.1 自检及 P01 原回放为历史基线。P02 本次开发对照来自同一段校准视频，独立验证等待另录的视频。成员2的接口和数据格式见 04_docs/成员2_接口接入.md。

如遇摄像头权限问题，检查 Chrome 或 Edge 对当前 localhost 地址的授权。模型无法加载时，确认 01_code/vendor 目录完整并从 HTTP 地址启动。MANIFEST.sha256.json 记录当前交付文件的校验值。
