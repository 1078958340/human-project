# P02 独立验证汇总

本轮用两段新原视频、13 次已注明的意图验证冻结配置。两段源视频的 SHA-256 不同，且均与校准视频不同。
根据原视频画面细化意图区间，再运行已核验 SHA-256 的配置。配对容差沿用冻结值，提前 100 毫秒、延后 350 毫秒。
第一个为命令轮。第二个是自然讲解中穿插明确指令的混合轮。全轮轨迹合计 79.468 秒。

## 漏检诊断

- C 的四次漏检都是张手。视频一的 7、10、21 秒均有动态候选，其张手模板距离约为 0.91–0.97，高于该类 0.30 的阈值。
- 视频二 39 秒附近的张手在画面中掌心向上。邻近候选留有追踪中断记录，候选范围为 39.268–40.068 秒，判定时刻为 40.335 秒。
