# 手势放映台技术复盘

## 当前实现与验证证据

MediaPipe 在浏览器提取手部关键点。自定义 v4 为双手分配轨迹 ID，将短动态动作按掌心位移或手型变化做带状动态时间规整（DTW），将静态手型与个人模板比较。类别间差距不足或接近反例时可拒识。识别后通过动作分发器驱动上一页、下一页和暂停状态。[识别器源码](public/gesture-engine/custom-gestures/recognizer.mjs) · [动作分发](public/gesture-engine/custom-gestures/actions.mjs)

A 用原个人示范及灵敏预设。B 从标注意图中补正例。C 逐条验证候选反例，保住 B 已命中的意图并检查额外触发。三组配置以 SHA-256 冻结，评估时共同使用另一段素材和同一标注。[校准实现](public/gesture-engine/custom-gestures/auto-study.mjs) · [实验包校验](public/gesture-engine/custom-gestures/study-exchange.mjs)

| 素材 | A 命中 / 误触 | B 命中 / 误触 | C 命中 / 误触 |
| --- | --- | --- | --- |
| P02 既有校准轨迹 | 2/5 · 9 次 | 3/5 · 9 次 | 5/5 · 0 次 |
| P02 另一段既有验证轨迹 | 4/9 · 0 次 | 7/9 · 0 次 | 7/9 · 0 次 |

合并前后的同机 Node.js 对照使用同一段 1,173 帧的 P02 校准轨迹。复用 DTW 的动态规划行并减少距离计算的临时数组后，本次计算用时从 29.9 秒降到 7.8 秒。校准与另一段验证轨迹中，A/B/C 的指标、触发动作和媒体时间戳一致。这是单机校准计算计时，包含逐条复验反例，现场翻页延迟另行测量。[DTW 实现](public/gesture-engine/custom-gestures/motion-distance.mjs)

## 优先级与实验设计

### 1. 按录制会话拆分数据，做消融实验

每人录制个人示范、校准试讲、未参与调参的命令轮和自然讲解轮。整段录像只进入一个集合，命令轮覆盖静态、动态、左右手与不同速度，自然轮保留指屏幕、摆手和拿笔等日常动作。先固定手势绑定、容差、页码边界和统计口径，再对同一测试集比较「原门槛 + 通用 DTW」「仅分通道」「分通道 + 灵敏门槛」，随后比较冻结的 A/B/C。这样能分别估计通道、门槛、正例和反例的贡献。

记录每人命令召回率、自然讲解每分钟误触次数、重复触发、错类和实际翻页成功率。每张表保留人数、意图总数和自然录像总分钟数。可以画出误触与召回的权衡，另用一条失败片段展示触发、拒识和播放器动作的不同阶段。

### 2. 用距离和反例间隔做逐类拒识

已有日志能给出距最近正例和最近反例的距离。针对每一类，在校准素材上搜索接受门槛和反例间隔，给正式放映中代价更高的误翻页更大权重。可先保留现有门槛作为数据不足时的默认值。用固定的验证轨迹对比默认门槛与逐类门槛，逐类报告召回、误触和错类，并查看低余量候选主要来自哪种手型或动作速度。

可加一组关键点稳定性的消融。在掌心运动和静态手型入口分别比较无滤波与 One Euro 滤波，检查光照变化、轻微抖动和遮挡恢复时的误触及延迟。快动作的调节会影响触发时刻，因此和门槛实验分开运行。[One Euro 滤波原作者说明](https://gery.casiez.net/1euro/)

### 3. 串起错误回看、确认和回滚

沿用时间轴的误触与漏检片段展示，为每条候选显示真实区间、预测动作、模板 ID、分数和拒识原因。在校准模式提供「确认正例」「确认反例」「跳过」，将人工确认写入新的配置修订，显示上一修订与当前修订的对照，便于恢复到较稳版本。独立评估保持冻结状态。可复用现有的 `applyConfirmedReviews` 和样例来源字段，重点实现界面交接与重跑记录。[标注对齐和人工复核接口](public/gesture-engine/custom-gestures/study.mjs)

### 4. 测量从摄像头帧到幻灯片呈现的时间

在视频帧回调记录媒体时间和浏览器时钟，分别测量关键点提取、分类、动作派发和页面绘制。真实试讲报告中列出 P50/P95、有效处理帧率和丢帧数，用命令起手与现场屏幕的同步记录衡量最终反应时间。若现场卡顿来自同步推理，可试验把 MediaPipe 放进专用 Worker，限制待处理帧数并丢弃过期帧。在相同分辨率和设备上比较延迟与识别指标。[MediaPipe Hand Landmarker 文档](https://developers.google.com/edge/mediapipe/solutions/vision/hand_landmarker?tab=Web) · [视频帧回调的时钟字段](https://developer.mozilla.org/en-US/docs/Web/API/HTMLVideoElement/requestVideoFrameCallback)

答辩可用同一段素材展示原始示范、一次校准后的配置和真实播放器结果，现场再用独立自然讲解片段展示每分钟误触。优先完成数据划分和逐类拒识实验，结果能直接对应现有的 A/B/C 表、时间轴和运行日志。
