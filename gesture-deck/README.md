# 手势放映台 · 三部分联调版

在本地浏览器注册个人手势、从试讲学习正反例，再用真实识别事件控制 PDF 或图片幻灯片。注册、校准和放映接入了 [团队识别与校准源码](https://github.com/1078958340/human-project/tree/50ef2e65a5130e0d090d26f488e57ce8645ee59c)。界面沿用 `design/` 的设计。

## 1. 启动

在 Windows 双击 `start-demo.cmd`，保留服务器窗口，在 Chrome 或 Edge 打开 [手势放映台](http://127.0.0.1:4178/)。从源码首次启动时，启动器使用 Node.js 安装依赖并构建网页。已有 `dist/` 时，可直接用 Python 3 启动。

从 macOS、Linux 或 Windows 终端启动时，在 `gesture-deck/` 使用 Node.js 22.13+（22 系列）或 24+，运行 `npm ci` 和 `npm run dev`。运行 `npm run build` 生成 `dist/`，可用 `npm run preview` 检查构建。摄像头由浏览器在 localhost 或 HTTPS 上请求授权，MediaPipe 模型和 WASM 随项目提供。

## 2. 体验放映

点右上角「体验放映示例」，合成轨迹会通过识别器控制示例幻灯片，演示翻页、暂停和恢复。可以在「正式放映」导出该次运行记录。

## 3. 注册自己的手势

1. 在「录手势」填写参与者编号，例如 `P03`。默认有一个绑定「下一页」的右滑手势。用「添加手势」创建自己的静态或短动态手势。
2. 开启摄像头，等到「已检测到手」再录制。静态手型摆好保持，短动态从静止开始只做一次动作，随后停住。每个手势建议录 3–5 段。示范可回放或移除。
3. 给手势绑定「下一页」「上一页」或「暂停／恢复手势翻页」。点击「开始手势试用」查看实际识别结果。
4. 导出个人配置。它保存关键点、动作绑定、修订和样例来源。现场录制的预览视频只在当前会话中可用，导入配置后可回放关键点。

## 4. 学习、冻结与独立评估

- **校准学习**使用当前个人配置，或在本页导入个人初始配置。选择试讲原视频，或导入带来源校验值的关键点轨迹。只在源视频画面已经镜像时勾选「原视频已经镜像」。
- **标记意图**在时间轴选择目标手势，定位并分别点击「标记起手」「标记结束」。也可导入与视频及参与者编号对应的标注 JSON。全段自然讲解且没有主动指令时，勾选「本段没有主动手势」。标记应覆盖本轮所有主动手势。
- **生成 A/B/C**点击「学习并冻结 A/B/C」。A 使用较灵敏设置和原示范，B 增加标注提取的正例，C 再吸收通过校准素材复验的反例。表格显示命中、漏检、误触、重复、错类和错动作。切换组别可定位并回看对应的片段。保存 C 配置与含校验值的冻结 A/B/C 实验包。
- **独立试讲评估**切换到「独立视频评估」，使用冻结实验包以及另一段原视频或其轨迹与标注。此操作只回放对比。程序校验配置哈希和时间容差，根据来源校验值拦截已用于该实验包校准或示范的视频。使用过的验证视频应在标注中保留既有复用标记。

### 新一轮实验录制

1. 在「录手势」每类录制 3–5 段个人示范，绑定动作并导出个人配置。
2. 单独录一段校准试讲，保留自然讲解，也安排每类手势的主动指令并标记起止。程序从有意图区间提取正例，从误触中筛选反例。冻结并导出 A/B/C 实验包。
3. 分开录命令轮和自然讲解轮，用同一份冻结包分别评估。给命令轮标出意图区间。全段没有主动手势时，在自然讲解轮勾选「本段没有主动手势」。分别导出两轮的报告、标注与轨迹。
4. 用第一批结果诊断漏检和误触。若据此调整模型或逐类门槛，将这批素材作为开发验证，并为最终测试留出另一批录像。

## 5. 正式放映与导出

导入一个 PDF 或按文件名自然排序的多张图片。选择自己的 C 配置并开启手势控制。暂停只暂停手势翻页，仍可用暂停／恢复手势恢复。播放器的手动按钮、空格键、方向键和全屏也可以使用。

运行记录包含应用版本、实际配置、素材名称和类型、起始页码、关键点、手势执行状态、翻页前后页码及可取得的浏览器绘制时刻。实时手势会话中的手动按钮、键盘翻页和暂停操作写入 `player.manualControl`。识别事件 `tMs` 使用媒体时间，`receivedPerfMs`、`executedPerfMs`、`presentedPerfMs` 统一用 `performance.now()` 采样。后台标签页或绘制未完成时，`presentedPerfMs` 可为空。离线跑分采用媒体时间，真人端到端延迟需要采集实际起手和显示时刻。

配置、标注和运行记录在当前浏览器会话内处理。刷新或关闭标签前用相应的导出按钮保存需要交接的文件。右上角「体验放映示例」使用一条合成轨迹展示上一页、下一页、暂停和恢复。

## 6. 源码与自检

- `public/gesture-engine/` 保留团队识别器、动作分发器、校准 worker 和本地模型。旧版 4.1 的 `recognizer-development.mjs` 与成员 1 的原交付一致。
- `src/team-adapter.js` 连接两个识别版本、视频追踪和校准 worker。 `src/presentation.js` 把 `next_page`、`previous_page` 和暂停事件转成播放器操作。 `src/rehearsal.js` 负责媒体、标注、结果与导出。
- 在 `gesture-deck/` 运行 `npm test` 检查两个引擎、配置兼容性和冻结包校验。

项目提供源码、示例幻灯片和标记示意视频。正式实验使用团队共享的个人配置、试讲原视频与配套标注。[技术复盘与答辩建议](TECHNICAL-REVIEW.md)
